# manifatura-skills

[![crates.io](https://img.shields.io/crates/v/manifatura-skills.svg)](https://crates.io/crates/manifatura-skills)
[![docs.rs](https://img.shields.io/docsrs/manifatura-skills)](https://docs.rs/manifatura-skills)

[Agent Skills](https://agentskills.io) for [manifatura](https://crates.io/crates/manifatura): skills found in `.agents/skills`, other directories and built into the app, a catalog for the system prompt, and a `skill` tool that loads one when a task calls for it.

Most programs depend on [`manifatura`](https://crates.io/crates/manifatura) instead, which re-exports this crate as `manifatura::skills` (`skills` feature, on by default).

- [API reference](https://docs.rs/manifatura-skills)
- Guide: [Skills](https://github.com/onatm/manifatura/blob/main/docs/skills.md)
- [manifatura's README](https://github.com/onatm/manifatura#readme)
